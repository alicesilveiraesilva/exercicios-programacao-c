# exercicios-programacao-c
Repositório com exercícios desenvolvidos durante meus estudos de programação em C, com foco em lógica de programação, estruturas de controle, validação de dados e processamento de informações.
Conteúdos que aparecem nessa lista
if / else
switch / case
for
while
do-while
break
continue
operadores relacionais e lógicos
contadores e acumuladores
cálculo de médias e porcentagens
validação de entrada
manipulação de caracteres com ctype.h
compilação e execução de programas em C

Isso é sustentado diretamente pelos seus códigos. Por exemplo, o exercício de votação usa switch, while, contadores e cálculo de porcentagens. Outro trabalha com for, identificação de números primos e break.
